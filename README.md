# Poja project STORED INT 
This project return a number on the file **stored-int.txt** if the file exist else if the file not exist generate number random create file **stored-int.txt** and stock the number in the file.
## If you want to test my load test with Artillery:
- First, Install artillery:
```bash
  npm install -g artillery
```
- and After that test the file with artillery:
```bash 
  artillery run load-test.yml
```

**N.B:**
If you touch or write the code in JAVA please don't forget to excute the file **format.sh** if you are in linux or MacOS, just like this:
```bash
    ./format.sh
```
and if you are in windowns just run : 
`.\format.bat`
